# Notchy releases

Release files for Notchy, clipboard history that lives in your Mac's notch. There's no source code here.

Each release has:
- `Notchy-<version>.zip`: the app
- `appcast.json`: the update feed Notchy reads to find new versions
- What's New images, if the release has any

The newest feed is always at `https://github.com/Zia-Bashir/notchy-releases/releases/latest/download/appcast.json`.

Install with Homebrew:

```bash
brew install --cask zia-bashir/tap/notchy
```
